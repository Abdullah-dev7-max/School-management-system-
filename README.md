# School management workspace

The runnable website is the Vite app in [`sms-portfolio`](./sms-portfolio/README.md).
Run commands from that folder; the loose JSX/SQL files directly in this
workspace root are standalone copies/utilities and are not imported by the Vite
app. `New folder` contains archive files, not website source.

Keep new application code, database changes, and package commands inside
`sms-portfolio`. Do not delete the root copies or archives until you have checked
whether you still need them.
